# Компаньон / Companion

Устанавливаемый плагин Koda Desktop. Агент ведёт по задаче в проекте или по упражнению в песочнице: разбивает её на шаги, открывает в файлах места для вашего кода, подсказывает по лестнице и мягко проверяет написанное. Сам агент код на диск не пишет.

## Использование

1. Выполните `npm ci` и `npm run pack` в корне этого репозитория.
2. Установите архив из `dist/` через «Маркетплейс → Установленные → Установить из файла». Для разработки выполните `npm run dev` и подключите папку репозитория.
3. Откройте «Компаньон» в боковом меню и начните задачу в одном из открытых проектов или упражнение.

Разрешения: `project.read` и `project.write` (файлы задачи и песочницы упражнений), `agent.run` (агент только читает проект и тратит запросы к модели), `process.run` (кнопка «Запустить» в упражнении). Задачи хранятся в `userData/plugin-data/dev.koda.companion`.

Устройство и правила описаны в `internal-docs/features/companion-plugin.md`.

## Проверки

```bash
npm run typecheck
npm test
npm run test:integration
```

Для `test:integration` нужен checkout Koda Desktop с установленными зависимостями в `../koda-app`. Другой путь можно задать через `KODA_DESKTOP_ROOT`.

Для проверки в Electron выполните `npm run test:companion:smoke` из Koda Desktop. Для другого расположения плагина передайте путь после `--`.

## Выпуск в каталог

Используйте Node.js 22.12 или новее. Тег `v<версия>` должен совпадать с версией в `koda-plugin.json`. Workflow `release.yml` проверит проект и приложит к GitHub Release архив и `SHA256SUMS`. Для записи в каталоге возьмите URL и SHA-256 из этого релиза. Формат записи описан в [KodaPlugins](https://github.com/XCode-NLP/KodaPlugins#формат-записи).
